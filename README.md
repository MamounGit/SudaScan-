# SudaScan

SudaScan هو تطبيق محلي (Local Agent) يعمل على نظام **Windows**، يهدف إلى حل مشكلة ربط أجهزة المسح الضوئي مع تطبيقات الويب مباشرة من المتصفح دون الحاجة إلى تحميل الملفات يدويًا أو استخدام حلول خارجية أو خدمات مدفوعة.

---

## نبذة عن المشروع

الفكرة الأساسية هي:

1. المستخدم يضغط زر "مسح" من داخل المتصفح أو أي نظام.
2. يتم تنفيذ عملية المسح عبر جهاز **Scanner**.
3. يظهر الملف مباشرة داخل النموذج (Form) أو يتم تنزيله تلقائيًا.

**مميزات الفكرة:**

- بدون رفع ملفات يدوي.
- بدون اتصال بالإنترنت.
- بدون خدمات خارجية.

---

## الخصائص الرئيسية

- يعمل محليًا على **Localhost**.
- لا يحتاج إلى اتصال إنترنت.
- لا يعتمد على خدمات مدفوعة أو محجوبة.
- واجهة ويب عربية بسيطة.
- يدعم الإخراج بصيغ **PNG** و **PDF**.
- واجهة API قابلة للاستهلاك من أي تطبيق.
- خفيف وسهل التشغيل.
- قابل للدمج في أي نظام ويب أو Desktop.

---

## المتطلبات التقنية

- نظام تشغيل **Windows 10** أو أحدث.
- **.NET 8 Runtime** مثبت.
- جهاز **Scanner** يدعم مكتبة **WIA**.
- متصفح حديث (**Chrome**, **Edge**, **Firefox**).

---

## طريقة التثبيت

1. قم بتنزيل ملف التثبيت (**Setup.exe**).  
2. شغّل ملف التثبيت واتبع خطواته.  
3. بعد الانتهاء، سيتم إنشاء اختصار للتطبيق.  
4. شغّل التطبيق من الاختصار.

---

## طريقة التشغيل

1. عند تشغيل التطبيق، يعمل كخدمة محلية (Local Agent).  
2. يفتح المتصفح تلقائيًا على العنوان:  
   `http://localhost:5050`  
3. ضع المستند داخل جهاز Scanner.  
4. اختر صيغة الإخراج (**PNG** أو **PDF**).  
5. اضغط زر "مسح الملف".  
6. سيظهر الملف مباشرة داخل الصفحة أو يتم تنزيله تلقائيًا.

---

## واجهة برمجة التطبيقات (API)

SudaScan يوفر واجهة HTTP بسيطة يمكن لأي نظام استهلاكها.

### نقطة النهاية الأساسية

| طريقة | Endpoint |
|-------|---------|
| POST  | `http://localhost:5050/scan` |

### المعاملات

| اسم المعامل | القيم الممكنة | الوصف |
|-------------|----------------|-------|
| `format`    | `png` , `pdf`  | صيغة الإخراج |

---

### مثال استهلاك الـ API من تطبيق ويب (JavaScript)

```javascript
fetch("http://localhost:5050/scan?format=png", {
    method: "POST"
})
.then(response => response.blob())
.then(blob => {
    const img = document.createElement("img");
    img.src = URL.createObjectURL(blob);
    document.body.appendChild(img);
});

using System.Net.Http;

var client = new HttpClient();
var response = await client.PostAsync(
    "http://localhost:5050/scan?format=pdf",
    null
);

var fileBytes = await response.Content.ReadAsByteArrayAsync();
File.WriteAllBytes("scan.pdf", fileBytes);
